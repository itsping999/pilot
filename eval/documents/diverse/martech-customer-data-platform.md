# 营销技术客户数据平台（CDP）

## 概述

客户数据平台（CDP）是营销技术的核心基础设施，它整合来自多个渠道的客户数据，构建统一的客户视图，支撑个性化营销和精细化运营。

## 数据采集

### 第一方数据
- 网站行为：页面浏览、点击、停留时间、滚动深度
- App 行为：启动、页面访问、功能使用、购买
- 交易数据：订单、退款、优惠券使用
- 客服数据：工单、聊天记录、满意度评分

### 数据接入方式
- SDK 集成：Web SDK、iOS SDK、Android SDK
- API 接入：REST API 批量导入历史数据
- 服务端埋点：后端事件推送
- 文件导入：CSV、Excel 批量导入

### 数据质量
- 实时校验：事件格式验证、字段类型检查
- 去重处理：基于事件 ID 的幂等处理
- 数据补全：IP 地理位置解析、设备信息补全
- 数据标准化：统一时间格式、货币单位、地址格式

## 身份识别

### 身份解析
- 确定性匹配：手机号、邮箱、会员 ID
- 概率性匹配：设备指纹、IP + User Agent 组合
- 跨设备识别：基于登录态关联多设备
- 匿名到已知：首次登录时关联历史匿名行为

### 用户画像
- 基础属性：年龄、性别、地域、职业
- 行为标签：活跃度、偏好品类、消费频次
- 预测标签：流失概率、购买意向、生命周期价值
- 自定义标签：业务特定的标签规则

## 分群与触达

### 分群引擎
- 规则分群：基于条件规则的静态分群
- 模型分群：基于机器学习的动态分群
- 实时分群：基于实时行为触发的即时分群
- RFM 模型：基于最近购买时间、频率、金额的分群

### 触达渠道
- 推送通知：App 推送、Web 推送
- 短信营销：验证码、营销短信
- 邮件营销：营销邮件、触发式邮件
- 广告投放：自定义人群包投放
- 站内触达：弹窗、Banner、消息中心

### A/B 测试
- 多变量测试：同时测试多个变量组合
- 流量分配：按用户 ID 哈希均匀分配
- 统计显著性：p-value < 0.05，最小样本量 > 1000
- 效果评估：转化率、点击率、ROI
