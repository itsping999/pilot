# RAG 系统优化指南

## 概述

检索增强生成（RAG）系统通过检索相关文档来增强大语言模型的回答质量。优化 RAG 系统需要关注检索质量、上下文构建、生成策略三个核心环节。

## 检索优化

### 分块策略
- 固定大小分块：按字符数或 token 数切分，简单但可能破坏语义
- 语义分块：按段落、章节或语义边界切分
- 递归分块：先按大结构切分，再按小结构细分
- 分块大小建议：200-1000 tokens，重叠 10-20%

### Embedding 模型选择
- 中文场景：BGE、M3E、text2vec-chinese
- 英文场景：text-embedding-3-small、E5、GTE
- 多语言场景：BGE-M3、multilingual-e5-large
- 评估指标：MTEB 排行榜、领域内检索准确率

### 混合检索
- 稀疏检索（BM25）+ 稠密检索（Embedding）
- 融合策略：RRF（Reciprocal Rank Fusion）
- 权重调优：根据查询类型动态调整稀疏/稠密权重
- 重排序：使用交叉编码器对候选结果重新排序

## 上下文构建

### 上下文窗口管理
- 动态调整：根据问题复杂度调整上下文大小
- 去重处理：移除高度相似的上下文片段
- 排序优化：将最相关的上下文放在开头或结尾
- 压缩策略：提取关键信息，减少冗余

### 多跳检索
- 问题分解：将复杂问题分解为子问题
- 迭代检索：基于中间结果进行补充检索
- 链式推理：逐步构建推理链
- 知识图谱：利用实体关系进行关联检索

## 生成优化

### Prompt 工程
- 系统提示：明确角色、规则、输出格式
- 少样本示例：提供 2-3 个回答示例
- 引导指令：要求引用来源、标注置信度
- 输出约束：限制回答长度、格式、语言

### 质量保障
- 幻觉检测：对比生成内容与检索上下文的一致性
- 引用验证：确保引用的来源真实存在
- 置信度评估：基于检索分数和生成质量评估置信度
- 回退策略：低置信度时返回"无法确认"而非猜测

## 评估体系

### 检索评估
- Recall@K：前 K 个结果中包含正确答案的比例
- MRR（平均倒数排名）：正确答案排名的倒数均值
- NDCG：考虑位置权重的排序质量指标

### 端到端评估
- 答案准确性：生成答案与标准答案的匹配度
- 答案完整性：是否覆盖了所有关键信息
- 引用准确性：引用的来源是否支持答案
- 响应延迟：端到端的响应时间
