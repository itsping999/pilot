### 为什么Ollama嵌入更好？

#### 1. 真正的语义嵌入
```python
# 哈希嵌入（确定性）
embedding = hash(text) % vector_size
# 只能捕获字符级相似性
```

#### 2. 中文优化

- 支持中英文混合

#### 3. 高维度向量
- 1024维向量（vs 128维）
- 捕获更多语义信息
- 区分细微差别
